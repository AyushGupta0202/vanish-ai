# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Automated CI/CD pipelines with GitHub Actions
- Automated version tagging and release generation
- CodeQL security scanning
- Dependabot for automated dependency updates
- Issue and PR templates
- Comprehensive documentation

### Changed
- Improved image upload optimization
- Enhanced canvas interaction with hand tool
- Better error handling and user feedback

## [1.0.0] - 2024-01-XX

### Added
- Initial release of Vanish AI
- AI-powered image inpainting using LaMa model
- Interactive canvas with brush and hand tools
- Auto-detection of text using OCR
- High-resolution image processing
- Docker support
- RESTful API with FastAPI
- React-based frontend with TypeScript
- GPU acceleration support (CUDA/Metal)
- Selective region processing
- Image history management (undo/redo)
- Download processed images

### Features
- Remove texts, logos, watermarks, and graphics from images
- 100% local processing (no cloud dependencies)
- GPU-accelerated inference
- Interactive mask drawing
- Auto text detection with OCR
- Configurable detection parameters
- Real-time preview
- Export in original quality
