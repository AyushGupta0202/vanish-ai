# Vanish AI Graphics Assets

This directory contains all graphics assets for Vanish AI.

## Logo Files

- `logo-wordmark.svg` - Full wordmark logo with disappearing "I" effect
- `logo-icon.svg` - Icon-only version (64x64)

## App Icons

- `app-icon-16.svg` - 16x16 favicon
- `app-icon-32.svg` - 32x32 favicon
- `app-icon-64.svg` - 64x64 app icon
- `app-icon-512.svg` - 512x512 app icon
- `app-icon-1024.svg` - 1024x1024 app icon

## Example Images

- `before-example.svg` - Before image for hero slider (landscape scene with logo)
- `after-example.svg` - After image for hero slider (logo removed)
- `before-example-2.svg` - Alternative before image (urban scene with billboard)
- `after-example-2.svg` - Alternative after image (billboard removed)

## Social Media

- `og-image.svg` - Open Graph preview image (1200x630)

## Usage

All SVG files are optimized and ready to use. They can be:
- Embedded directly in HTML/React
- Used as `src` attributes for `<img>` tags
- Converted to PNG/JPG using image conversion tools if needed
