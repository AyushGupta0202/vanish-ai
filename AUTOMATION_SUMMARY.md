## 📝 Quick Commands

### Update Topics
```bash
# Edit .github/repo-metadata.yml
git add .github/repo-metadata.yml
git commit -m "chore: update repository topics"
git push origin main
# → Auto-syncs topics
```

### Create Release
```bash
./scripts/release.sh patch  # or minor/major
git push origin v1.0.1
# → Auto-creates release with changelog
```

### Generate Release Notes
```bash
./scripts/generate-release-notes.sh v1.0.0 v1.1.0
```

### Check Activity
